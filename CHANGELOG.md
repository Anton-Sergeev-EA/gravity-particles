# Changelog

## 2.0.0

### Интерфейс и локализация
- Многоязычный интерфейс: русский (основной), English, 中文, हिन्दी, Español, Français, Deutsch, Italiano; переключение на лету (панель или `L`).
- Текстовый движок на HarfBuzz + FreeType с цепочкой шрифтов Noto (латиница/кириллица → деванагари → китайский), перенос строк с учётом CJK.
- Встроенные подмножества шрифтов Noto (~1 МБ) и скрипт `tools/subset_fonts.py` для их пересборки.
- Панель настроек, HUD, справка (F1), всплывающие уведомления, прокрутка панели, поддержка HiDPI.
- Автоопределение языка системы (Linux, Windows, macOS), локальные форматы чисел.
- Локализованные заголовок окна, справка командной строки и сообщения об ошибках; `.desktop`-файл с переводами.

### Графика
- Физика частиц перенесена на видеокарту (transform feedback): до 1 000 000 частиц.
- Чёрные дыры: горизонт событий, фотонное кольцо, гравитационное линзирование; поглощение частиц.
- Спиральные галактики: орбитальное рождение частиц, экспоненциальный профиль диска, логарифмические рукава; новая дыра собирает собственный диск.
- Частицы со смазом движения, шлейфы, процедурная туманность, звёзды разной цветовой температуры с дифракционными лучами.
- Пост-обработка: mip-bloom (13-точечный фильтр + взвешивание Кариса), ACES, адаптация экспозиции, хроматическая аберрация, виньетка, зерно, цветокоррекция, ударные волны, тряска камеры.
- Палитра «Пламя», «Радуга» как спектральное колесо; пресеты качества «Низкое / Среднее / Высокое / Ультра».
- Ресурсы (шейдеры, переводы, шрифты) копируются в каталог сборки при каждой сборке, а не только при перелинковке.

### Симуляция
- До 1 000 000 частиц, логарифмическая шкала количества частиц.
- Настраиваемые сила гравитации, свечение, размер частиц; пауза; затухание скорости не зависит от частоты кадров.
- Скриншоты в PNG (F12) в фоновом потоке; полноэкранный режим (F11).

### Исправления
- При перетаскивании нового источника за курсором больше не «тянутся» все ранее созданные источники.
- Частицы возвращаются в центр текущего окна после изменения его размера; звёздный фон перестраивается под новый размер.
- Координаты мыши корректны на HiDPI-экранах (framebuffer ≠ размер окна).
- Новые частицы видны сразу, даже если симуляция на паузе.
- Счётчик FPS показывал не меньше 30 при любом реальном FPS (считался после ограничения шага времени).

### Инфраструктура
- Установка на Linux одной командой: `scripts/install-linux.sh` (зависимости, сборка, ярлык в меню, удаление через `--uninstall`).
- README на 8 языках, понятный без технической подготовки, со скриншотами и контактами автора.
- Настройки сохраняются между запусками (`settings.ini`, атомарная запись).
- Параметры командной строки: `--lang`, `--particles`, `--fullscreen`, `--list-languages`, `--version`, `--help`.
- Модульные тесты (`ctest`) и CI на GitHub Actions; поиск ресурсов относительно исполняемого файла; `cmake --install`.
